# tvbox

收集自互联网的 TVBox / FongMi 多仓接口，**每条都实测过**，失效的会及时删。

| 项 | 值 |
|---|---|
| 订阅地址 | `https://raw.githubusercontent.com/lizi94/tvbox/main/tvbox.json` |
| 国内加速 | `https://gh-proxy.com/https://raw.githubusercontent.com/lizi94/tvbox/main/tvbox.json` |
| 线路数 | 19 条（全部实测可用，按延迟升序） |
| 最后实测 | 2026-10-26 |
| 客户端 | FongMi/TV 及衍生（多仓 `urls` 协议） |

## 一、怎么用

1. 打开 设置 → 点播 → 配置地址，粘贴上面的**订阅地址**，确定。
2. 本文件是多仓格式：客户端会**自动载入第一条（凯速单仓）**，其余 18 条同时注册进配置列表，
   之后可在 设置 → 点播 → 配置 里随时切换，不用重新粘贴地址。
3. 首次载入会下载 `spider.jar`（约 1–3 MB），慢一两秒属正常。

> 说明：FongMi 的 depot 解析逻辑（`VodConfig.parseDepot`）是「注册全部 + 载入第一个」，
> 所以**第一条要能立刻出片**。本文件按实测延迟升序排，第一条即最快的可用源。

## 四、三层校验标准

只看「能不能打开」会误判，很多接口能返回 JSON 但站点全废。本仓库按三层筛：

1. **配置层**：HTTP 200 且是合法 JSON（兼容 `//`、`#` 注释、尾逗号、`2423` AES 加密格式）。
2. **站点层**：`sites` 非空，不能是 `storeHouse`（影视仓私有格式）或嵌套多仓。
3. **spider 层**：配置里 `spider` 指向的 jar 必须能下载，且 MD5 对得上（或客户端会重新下载）。
   这一层最容易翻车：俊哥、小苹果、小盒子4K 都是配置正常但 jar 挂掉，站点全军覆没。
